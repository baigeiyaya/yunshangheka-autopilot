# 云上河开 自动推进器

河南开放大学「云上河开 (AI学通)」学习平台的油猴脚本。自动播放、自动关闭完成弹窗、自动切换到下一个学习资源。

> 学时按平台真实计时累积，本脚本只负责**省去手工点击**，不改变学时计算规则。

## 功能

- **自动播放**：进入学习页自动接管 `<video>`，静音播放
- **自动关闭弹窗**：检测到「您已完成当前资源」时自动点击「确定」
- **自动切换资源**：根据课程目录树（zTree）的 `url` 字段跳转到下一个资源
- **文档资源处理**：PPT / Word 等无视频页面停留指定时间后自动跳转
- **跳过作业/测验**：可开关，避免卡在需要人工完成的节点
- **暂停按钮**：随时中断

## 安装

### 前提

1. 浏览器安装脚本管理器：[ScriptCat（脚本猫）](https://scriptcat.org/) 或 [Tampermonkey（油猴）](https://www.tampermonkey.net/)
2. **开启开发者模式 / 允许用户脚本**（新版 Chrome / Edge 必需）
   - `edge://extensions/` 或 `chrome://extensions/`
   - 打开「开发者模式」
   - 脚本管理器详情页中开启「允许用户脚本」

### 安装脚本

**方式一**：把 `yunshangheka-autopilot.user.js` 拖进浏览器窗口

**方式二**：脚本管理器 → 新建脚本 → 粘贴文件内容 → 保存

## 使用

进入 `jx.open.ha.cn` 的任意课程学习页，页面右侧会出现控制面板：

| 控件 | 说明 |
|---|---|
| 状态行 | 实时显示播放进度 / 等待状态 / 跳转动作 |
| 跳过作业/测验 | 默认开启 |
| 下一个 | 手动强制跳转 |
| 暂停 | 暂停/恢复自动推进 |

## 匹配范围

```
*://*.open.ha.cn/jxpt-web/student/activity/*
```

## 实现要点

脚本不模拟 DOM 点击来切换章节，而是读取 zTree 课程目录数据：

```js
var tree = window.jQuery.fn.zTree.getZTreeObj('courseContent');
// 每个节点带 id（即 activityId）和 url（直接可跳转的地址）
// 找到当前 activityId 对应的节点，取其下一个有 url 的节点
location.href = nextNode.url;
```

这比模拟点击稳定，不受页面结构变化影响。

## 注意事项

- **学时按真实时间累积**：平台心跳上报 `timePoint`，但学时按真实经过时间计算，倍速无效
- **挂机需保持页面在前台**：后台标签页会被浏览器节流
- **关闭睡眠标签页**：Edge 设置 → 系统和性能 → 关闭「使用睡眠标签页」
- **防止系统休眠**：电源设置中把睡眠设为「从不」
